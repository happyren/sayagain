# Examples

Planned, in order:

1. `stdio-passthrough` — wrap a local MCP server with Layer 0 and watch the
   ledger fill.
2. `http-postgres` — the proxy in front of a remote server with a Postgres
   dead-letter queue and the replay CLI.
3. `intent-shim` — the schema shim capturing intent from a stock host, with
   the fill-rate experiment harness.
4. `lint-ci` — `@sayagain/lint` as a GitHub Action on an MCP server repo.
